# ALBi landing page

A React/Vite scaffold of the supplied ALBi landing-page mockup. The first pass
keeps the desktop composition pixel-aligned to the 1672×941 reference while
providing real controls for the navigation, primary calls to action, and wish
categories.

## Run locally

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
```

The controls are intentionally inert for this visual-scaffolding phase. Their
handlers can be added in `src/App.jsx` without changing the layout.
